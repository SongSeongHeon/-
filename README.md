## 이런 점이 좋아요

- **답을 직접 적으면 자동으로 채점**해요. 대소문자와 띄어쓰기는 무시하고, 같은 뜻의 다른 표기도 인정해요.
- **해설이 220문제 모두에** 있어요. 코드 문제는 값이 변하는 순서대로 풀이했어요.
- **정답을 어떻게 확인했는지** 문제마다 표시해요. 코드는 실제로 실행했고, SQL은 실제 DB에 넣어 돌렸어요.
- **여러 회차에 반복된 개념**에 "같은 개념 N회 출제" 표시가 붙어서, 자주 나오는 것부터 공부할 수 있어요.
- **영역별 정답률 통계**로 약한 영역을 바로 알 수 있어요.
- 틀린 문제, 체크한 문제, 메모한 문제를 **복습 탭**에 모아 줘요.
- 모르는 부분은 **AI에게 바로 물어볼 수 있어요.** 문제와 코드, 정답, 해설이 자동으로 같이 전달돼요. (내 Gemini 키 필요, [사용법](#ai-도우미-gemini))

## 문제 푸는 방법

### 기본 흐름
1. 문제를 읽고 답을 적거나 골라요.
2. **채점하기**를 눌러요. (모르겠으면 **정답 보기**)
3. 정답, 해설, 정답 확인 방법이 나와요.
4. **다음 문제**로 넘어가요.

정답이면 초록색 ○, 오답이면 빨간색 ╱ 도장이 찍혀요.

### 이어서 풀기
문제를 풀다가 `나가기`를 누르거나 폰의 **뒤로가기**를 눌러도 앱이 닫히지 않고 홈 화면으로 돌아와요. 홈의 **이어서 풀기** 카드를 누르면 풀던 곳에서 다시 시작해요.
- 풀던 문제 목록, 현재 번호, 이미 채점한 결과, 쓰던 답까지 그대로 복원돼요.
- 앱을 껐다 켜도 남아 있어요. (그 기기의 브라우저에 저장돼요)
- 끝까지 풀어서 결과 화면이 나오면 사라지고, `지우기`로 직접 지울 수도 있어요.
- 새로 풀기를 시작하면 이어서 풀기는 새 풀이로 바뀌어요. (한 번에 하나만 저장돼요)

### 문제 유형별 답 입력

| 유형 | 입력 방법 |
|---|---|
| 직접 쓰는 문제 | 입력칸에 답을 적어요. 칸이 여러 개면 번호별로 적어요. 코드가 **여러 줄을 출력**하면 출력되는 줄 그대로 줄을 바꿔서 적어요. (공백이나 줄바꿈이 다르면 오답이에요. 한 줄에 공백으로 이어 쓰는 것은 인정해요.) |
| 보기에서 하나 고르기 | 보기를 눌러 선택해요. |
| 보기에서 여러 개 고르기 | 해당하는 보기를 모두 체크해요. |
| 순서대로 고르기 | 누르는 순서대로 번호가 붙어요. 다시 누르면 취소돼요. |
| 칸마다 하나씩 고르기 | 칸별로 알맞은 보기를 골라요. |

### 빈칸 표시
문제 글이나 코드 안의 빈칸 `( )`, `( 1 )`, `( ① )`, `____` 등을 **노란색 박스**로 표시해요.
이미지 속에 빈칸이 있는 문제는 그렇게 안내해 줘요.

### 문제 화면의 도구

| 도구 | 위치 | 설명 |
|---|---|---|
| **문제 목록** | 위쪽 격자 아이콘 | 번호판이 열려요. 맞음(초록), 틀림(빨강), 체크(노란 점)를 한눈에 보고 원하는 번호로 이동해요. |
| **체크 ☆** | 위쪽 별 아이콘 | 나중에 다시 볼 문제를 표시해요. 복습 탭에 모여요. |
| **코드 줄 표시** | 코드의 줄을 누르기 | 그 줄에 노란 표시가 돼요. 다시 누르면 해제돼요. 값을 따라가며 풀 때 편해요. |
| **내 메모** | 문제 맨 아래 | 헷갈린 점이나 외울 키워드를 적어요. 검색에서도 찾아져요. |
| **AI에게 물어보기** | 문제 카드 아래, 위쪽 반짝이 아이콘 | AI 대화창이 열려요. [자세히](#ai-도우미-gemini) |
| **원문 보기** | 문제 카드 아래 | 문제를 가져온 블로그 글로 이동해요. |

## 채점과 해설

### 자동 채점 규칙
- 직접 쓰는 문제는 대소문자와 띄어쓰기를 무시해요.
- 개념 문제는 같은 뜻의 다른 표기를 인정해요. (예: `OSPF` 또는 `Open Shortest Path First`)
- 코드 출력 문제는 출력 글자를 그대로 비교해요.
- IP 주소처럼 정답이 여러 개일 수 있는 문제는 조건에 맞으면 정답으로 봐요.

### 채점이 다르면

**정답 고치기** (정답이 틀렸거나 자동 채점이 이상할 때)
1. 정답 화면의 **자동 채점이 이상한가요? 정답 고치기**를 눌러요.
2. 열린 편집기에서 정답을 고쳐요. 한 줄이 한 칸의 정답이에요. 번호가 있는 칸은 `1. 값`처럼 적고, 같은 뜻의 다른 표기는 `또는`으로 이어요.
3. **저장하고 다시 채점**을 누르면 고친 정답이 이 기기에 저장되고, 내 답을 바로 다시 채점해요.
4. 고친 정답에는 **내가 고친 정답** 표시가 붙고, `원래 정답으로 되돌리기`로 언제든 되돌릴 수 있어요. (`더보기`에 고친 정답 목록이 있어요.)
- 보기에서 고르는 문제는 값을 쉼표로 적어요. 예: `ㄱ, ㄹ`
- 채점 규칙이 따로 있는 일부 문제(여러 답 중 하나, 집합, IP 주소 등)는 정답 표시만 바뀌어요. 이때는 `맞았어요 / 틀렸어요` 버튼으로 채점을 고쳐 주세요.
- 고친 정답은 기록 백업에 들어가요.

**그 밖의 방법**
- **직접 바꾸기**: 채점 뒤 아래의 `맞았어요 / 틀렸어요` 버튼으로 결과를 고칠 수 있어요.
- **인정한 답으로 저장**: 틀림으로 나온 답을 `맞았어요`로 바꾸면 "앞으로 정답으로 인정할까요?"라고 물어봐요. 인정하면 다음부터 같은 답이 정답으로 처리돼요. 인정한 답은 `더보기`에서 지울 수 있어요.

### 정답 확인 표시
정답 아래에 어떻게 확인했는지 표시돼요.

| 표시 | 뜻 |
|---|---|
| **실행 검증** | 코드를 실제로 실행해서 출력이 정답과 같은 걸 확인했어요. |
| **DB 실행 검증** | 표 데이터를 실제 DB(SQLite)에 넣고 SQL을 실행해서 확인했어요. |
| **계산 검증** | 스크립트나 직접 계산으로 정답을 다시 구해서 확인했어요. |
| **이미지 대조** | 문제 이미지의 표와 그림을 정답과 맞춰서 확인했어요. |
| **원문 대조** | 기출문제집 PDF의 원문 문제와 보기를 확인해서 바로잡았어요. (2023년 1회 5, 8, 11, 12, 18번) |
| **원문 정답** | 블로그 원문의 정답을 그대로 실었어요. 따로 검증하지는 못했어요. (주로 개념 문제) |
| **확인 필요** | 원문 표기가 특이하거나 코드에 오류가 있는 문제예요. 안내 문구를 꼭 읽어 주세요. |

현재 기준으로 실행 검증 88문제, DB 실행 검증 17문제, 계산 검증 12문제, 이미지 대조 35문제, 원문 대조 5문제, 원문 정답 79문제, 확인 필요 7문제예요. (한 문제가 여러 방식으로 확인된 경우도 있어요.)

## 복습과 학습 도구

### 같은 개념 N회 출제
같은 개념이 여러 회차에 다시 나온 문제에 붙는 표시예요. 정답 화면에서 관련 문제로 바로 이동할 수 있어요.
통계의 **자주 나오는 개념**에서는 반복 출제된 순서대로 보여줘요.

### 키워드 카드
1. `카드` 메뉴에서 영역과 순서(빈출 먼저, 출제 순서, 섞어서)를 골라요.
2. 설명을 읽고 어떤 용어인지 떠올려요.
3. **답 보기**로 확인한 뒤 `알아요` 또는 `헷갈려요`를 눌러요.
4. 헷갈리는 카드만 모아서 다시 볼 수 있어요.

### 통계
`영역별`, `유형별`, `회차별`, `자주 나오는 개념`, `자주 틀리는 문제`는 눌러서 펼쳐 볼 수 있어요. 처음에는 접혀 있어요.
영역마다 `틀린 문제`, `안 푼 문제` 버튼으로 바로 풀 수 있어요.

### 검색
단어를 띄어 쓰면 **모두 들어간 문제**만 보여줘요. 예: `static 출력`
찾은 부분이 노란색으로 강조되고, 결과를 누르면 그 문제로 이동해요.

## AI 도우미 (Gemini)

풀다가 막힌 문제를 AI에게 바로 물어볼 수 있어요. 각자 **자기 Gemini 키**를 넣어서 쓰는 방식이라, 키는 내 기기의 브라우저에만 저장되고 이 앱에는 서버가 없어요.

### 처음 한 번 설정하기 (2분)

1. [Google AI Studio 키 페이지](https://aistudio.google.com/app/apikey)를 열고 구글 계정으로 로그인해요.
2. **API 키 만들기(Create API key)** 버튼을 눌러요. 프로젝트를 고르라고 하면 새 프로젝트로 만들거나 기본값을 골라요.
3. 만들어진 키를 복사해요. 키 상세 창의 **API 키** 칸이나 **키 복사** 버튼을 쓰면 돼요. 지금은 `AQ.`로 시작하는 긴 글자예요. (예전에 만든 키는 `AIza`로 시작해요.)
4. 앱의 `더보기` → **AI 도우미 (Gemini)** 칸에 붙여 넣고 **저장**을 눌러요.
5. **연결 테스트**를 눌러 "연결됐어요"가 나오면 끝이에요.

> 키를 만드는 화면의 모양이나 버튼 이름은 Google이 바꿀 수 있어요. 이름이 조금 달라도 "API 키 만들기" 메뉴를 찾으면 돼요.

### 모델 고르기

`더보기` → **AI 도우미 (Gemini)** → **모델**에서 네 가지 중에 골라요. 누르면 바로 저장돼요.

| 선택 | 설명 | 모델 이름 |
|---|---|---|
| **Gemini 3.5 Flash-Lite** | 가장 빠른 답변 | `gemini-3.5-flash-lite` |
| **Gemini 3.6 Flash** (기본) | 무엇이든 도움을 받아요 | `gemini-3.6-flash` |
| **Gemini 3.1 Pro** | 고급 추론. 느리고 무료 한도가 더 적을 수 있어요 | `gemini-3.1-pro-preview` |
| **직접 입력** | 원하는 모델 이름을 적어요 | 예: `gemini-3.8-flash` |

- 기본은 **3.6 Flash**예요. 그대로 쓰면 돼요.
- **직접 입력**은 Gemini API 문서의 모델 이름(소문자, 숫자, 점, 하이픈)을 그대로 적고 **저장**을 누르면 돼요.
- Gemini 앱에 보이는 이름과 API 이름이 다를 수 있어요. 예를 들어 앱의 `3.1 Pro`는 API에서 `gemini-3.1-pro-preview`예요.
- 안 될 때는 **연결 테스트**로 확인하고, 다른 모델로 바꿔 보세요.

### 쓰는 방법

- 문제 화면의 **AI에게 물어보기** 버튼이나 위쪽 반짝이 아이콘을 누르면 대화창이 열려요.
  - 폰에서는 아래에서 올라오는 창으로, **PC 넓은 화면에서는 문제 옆 패널**로 떠요.
- 문제, 코드, 이미지, 내 답, 정답, 해설이 **자동으로 같이 전달돼요.** 따로 설명할 필요가 없어요.
- 아래 **빠른 질문 버튼**을 눌러도 돼요. 예: `힌트만 줘`, `한 줄씩 값이 어떻게 변하는지 설명해줘`, `내 답이 왜 틀렸는지 알려줘`, `비슷한 문제를 하나 내줘`
- 다른 문제로 넘어가면 대화창이 그 문제의 대화로 바뀌어요. 대화는 문제별로 저장돼요.
- AI 답변 아래 **메모에 추가**를 누르면 내 메모에 저장돼요.
- **정답을 확인하기 전에는 힌트 위주로** 알려줘요. 바로 정답이 필요하면 "정답을 알려줘"라고 물어보세요. (`더보기`에서 끌 수 있어요.)

### AI 예상문제 출제
`학습` → **AI 출제**에서 기출 형식의 새 문제를 만들어요. (내 Gemini 키가 필요해요)

1. **영역**을 골라요. (C, Java, Python, SQL, 데이터베이스, 소프트웨어 공학, 테스트, 네트워크, 보안, 운영체제, 알고리즘)
2. **유형**을 골라요. `개념` / `코드 해석` / `코드 빈칸 채우기` (코드 유형은 C, Java, Python, SQL 영역에서만 고를 수 있어요.)
3. **문제 수**(3, 5, 10개)와 **난이도**(쉽게, 기출 수준, 조금 어렵게)를 골라요.
4. **AI로 문제 만들기**를 누르면 10~30초쯤 뒤에 풀이 화면이 열려요.

- 같은 영역의 실제 기출 문제를 예시로 같이 보내서 기출과 비슷한 형식으로 만들어요.
- AI가 만든 문제는 **AI 생성** 표시가 붙고, 기출 문제와 따로 관리돼요. 통계와 정답률에는 섞이지 않아요.
- 자동으로 채점하고 해설도 나와요. 이상하면 `정답 고치기`로 바로잡을 수 있어요.
- 만든 문제는 이 기기에 **최근 60개**까지 저장돼요. 같은 화면의 **이전에 만든 예상문제**에서 다시 풀거나 지울 수 있어요. 기록 백업에도 들어가요.

> ⚠️ **AI가 만든 문제는 정답이 틀릴 수 있어요.** 특히 코드 출력은 AI가 실행해 보지 않고 추적해서 쓴 값이라, 코드를 직접 따라가 보거나 실행해서 확인해 주세요. 정답 검증 표시(실행 검증 등)는 기출 문제에만 있어요.

### 폰이나 다른 기기로 키 옮기기
PC에서 한 번 설정했다면 폰에서 다시 만들 필요가 없어요.

1. 설정한 기기에서 `더보기` → **다른 기기로 키 옮기기** → **연결 링크 복사**를 눌러요.
2. 링크를 카카오톡 `나와의 채팅` 같은 곳에 붙여 넣어요.
3. 폰에서 그 링크를 열면 "키를 이 기기에 저장할까요?"라고 물어봐요. **확인**을 누르면 끝이에요.
4. 저장된 뒤에는 보낸 메시지를 지우세요.

링크에는 키가 들어 있어요. 남에게 보내지 마세요. 링크를 열면 주소창에서 키가 바로 지워져요.

### 키 없이 쓰기
키가 없어도 대화창에서 **질문 복사하고 Gemini 열기**를 누르면 문제 내용이 복사되고 Gemini 웹이 열려요. 붙여 넣고 질문만 이어서 쓰면 돼요.

### 알아두세요

- **비용**: AI Studio의 무료 등급은 카드 등록 없이 쓸 수 있어요. 대신 분당, 하루 요청 수에 한도가 있어요. 한도는 모델과 시기마다 달라서 AI Studio에서 내 한도를 확인해 주세요. 한도를 넘으면 잠시 뒤에 다시 하면 돼요.
- **개인정보**: 질문 내용(문제, 내 답, 대화)이 Google로 전송돼요. 무료 등급에서는 입력한 내용이 Google의 모델 개선에 쓰일 수 있다고 알려져 있어요. 자세한 건 Google 약관을 확인해 주세요. 풀이 기록, 메모, 체크는 보내지 않아요.
- **키 관리**: 키는 비밀번호처럼 다뤄 주세요. 남에게 알려주거나 캡처로 공유하지 마세요. 공용 PC에서는 쓴 뒤 `더보기`에서 **키 삭제**를 누르세요. 키가 노출됐다면(캡처에 찍힌 경우 포함) AI Studio에서 그 키를 삭제하고 새로 만드세요.
- **정확도**: AI 답변은 틀릴 수 있어요. 정답 표시와 해설을 먼저 확인하고, AI는 이해를 돕는 용도로 써 주세요. 정답이 실행 검증된 문제는 AI에게도 "뒤집지 말라"고 알려주지만, 설명이 틀릴 수는 있어요.
- **백업**: 대화 내용은 기록 백업에 들어가지만, **키는 백업에 들어가지 않아요.** 기기를 바꾸면 키를 다시 넣어야 해요.

## 기록 저장과 백업

풀이 결과, 체크, 메모, 카드 상태, 인정한 답, AI 대화, 설정은 **지금 쓰는 기기의 브라우저에만** 저장돼요. 이 앱의 서버로는 전송되지 않아요. (AI 질문은 내 키로 Google에 직접 전송돼요.)

- 폰과 PC의 기록은 **서로 합쳐지지 않아요.**
- 브라우저 데이터를 지우거나 시크릿(비공개) 모드를 쓰면 **기록이 사라질 수 있어요.**
- 같은 링크를 여러 사람이 써도 기록은 각자 따로예요.

### 백업하기
`더보기` → **기록 내보내기**
- **파일로 저장**: `정처기-기록-날짜.json` 파일이 내려받아져요.
- **텍스트로 보기와 복사**: 파일 저장이 불편한 폰에서 써요. 복사해서 메모 앱이나 메신저에 붙여 넣어 보관하세요.

### 불러오기
`더보기` → **기록 불러오기**
- 저장해 둔 파일을 고르거나, 복사해 둔 텍스트를 붙여 넣고 **불러오기**를 눌러요.
- 불러오면 지금 기록이 **불러온 내용으로 바뀌어요.**

기기를 바꾸기 전이나 브라우저 정리 전에는 한 번 백업해 두세요.

### 설정
`더보기` → **보기 설정**에서 코드 줄 번호를 켜고 끌 수 있어요.

## 자주 묻는 질문

**풀이 기록이 사라졌어요.**
기록은 그 기기의 브라우저에만 저장돼요. 브라우저 데이터를 지웠거나, 다른 기기나 다른 브라우저로 열었거나, 시크릿 모드였다면 보이지 않아요. 평소에 `더보기`에서 백업해 두면 복원할 수 있어요.

**이미지가 안 보이고 "이미지가 필요해요"라고 나와요.**
`img` 폴더가 올라가지 않았거나 파일 이름이 다른 경우예요. `더보기` → **필요한 이미지 점검**에서 어떤 파일이 없는지 확인할 수 있어요.

**정답인데 틀렸다고 나와요.**
표기가 많이 다른 경우예요. `맞았어요`를 눌러 고치고 "인정한 답으로 저장"을 선택하면 다음부터 정답으로 처리돼요.

**정답인데 틀렸다고 나오거나, 틀렸는데 정답이라고 나와요.**
정답 화면의 **정답 고치기**로 바로잡을 수 있어요. 여러 줄을 출력하는 코드 문제는 줄이 달라지면 오답이에요. (예: `Art`를 `A`, `r`, `t` 세 줄로 나눠 쓰면 오답)

**정답이 이상해 보여요.**
문제는 실제 시험을 기억으로 복원한 거라 보기나 정답이 원문과 다를 수 있어요. 정답 아래의 **정답 확인 표시**와 **확인 필요** 안내를 먼저 보고, **원문 보기**로 블로그 글도 확인해 보세요.

**AI 도우미가 "키가 올바르지 않아요"라고 해요.**
키가 일부만 복사됐거나 중간에 줄바꿈이나 공백이 들어간 경우가 많아요. AI Studio의 **키 복사** 버튼으로 키 전체를 다시 복사해 붙여 넣어 보세요. 키는 `AQ.`(새 형식) 또는 `AIza`(예전 형식)로 시작해요.

**"키를 인증하지 못했어요(401)"라고 나와요.**
키를 다시 복사해 보고, 그래도 안 되면 AI Studio에서 새 키를 만들어 다시 넣어 보세요. 키가 삭제됐거나 정지된 건 아닌지도 확인해 주세요.

**AI 도우미가 "요청 한도를 넘었어요"라고 해요.**
무료 등급은 분당, 하루 요청 수에 한도가 있어요. 1분쯤 뒤에 다시 해 보고, 계속되면 오늘 한도를 다 쓴 거예요. `더보기`의 모델에서 `Gemini 3.5 Flash-Lite`처럼 가벼운 모델로 바꿔 보는 것도 방법이에요.

**AI 도우미가 "모델을 찾을 수 없어요"라고 해요.**
모델 이름이 바뀌었거나 내 키에서 쓸 수 없는 모델이에요. `더보기`의 모델에서 다른 모델을 고르거나, **직접 입력**한 이름이 맞는지 확인해 주세요.

**인터넷 없이도 되나요?**
처음 열 때와 이미지를 불러올 때, AI 도우미를 쓸 때는 인터넷이 필요해요. 폰트는 기기에 있는 한글 글꼴을 우선 써요.

**폰에서 화면이 이상해요.**
브라우저를 최신으로 업데이트하고 새로고침해 보세요. 그래도 같으면 기기와 브라우저 종류를 알려 주세요.

## 파일 구성과 문제 추가

```
Engineer_Information_Processing/
├─ README.md
├─ index.html      앱 전체 (화면, 문제, 해설, 채점 규칙이 한 파일에 들어 있어요)
└─ img/            문제 이미지 35장
```

### 이미지 파일 이름
`연도-회차-번호(2자리).png` 형식이에요. 예: 2023년 1회 13번 → `img/2023-1-13.png`
한 문제에 이미지가 여러 장이면 `-1`, `-2`를 붙이고, 정답에 들어가는 이미지는 `-a`를 붙여요.

### 문제 추가
`index.html` 안의 데이터 구역에 `ROUNDS.push({year, round, src, questions:[...]})` 블록을 하나 더 만들면 돼요.
영역(`area`)은 C, Java, Python, SQL, 데이터베이스, 소프트웨어 공학, 테스트, 네트워크, 보안, 운영체제, 알고리즘, 기타 중에서 고르고, 유형(`type`)은 `code`, `concept`, `fill`, `calc` 중에서 골라요.
해설은 `EXPL`, 채점 방식 예외는 `SPEC`, 빈출 묶음은 `TOPICS`, 검증 표시는 `VERIFY`에 같은 문제 번호(`"2026-1-5"` 형식)로 추가해요.

### 내 컴퓨터에서 열기
`index.html`과 `img` 폴더를 같은 위치에 두고 `index.html`을 브라우저로 열면 돼요.
